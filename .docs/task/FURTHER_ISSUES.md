# 后续问题（Further Issues）

> **定位**：本期**不解决**、需要结转 / 留池 / 排到后续的问题，是「下一期该处理什么」的**结转池**。
> **来源**：从 `CURRENT_ISSUES.md` 结转、评审「留池」、或开工前已知但**主动裁剪**的事项。
> **与 `CURRENT_ISSUES.md` 的分工**：本期解决 → CURRENT；本期不解决 → 本文件。**编号各自独立**，
> 从 CURRENT 结转过来的**保留原 I-## 编号**并在「来源」列标注。
> **膨胀控制**：每条必须有明确去向（下期任务 / 留池待评审 / 废弃）；已消化的直接删除（历史在 git）。
