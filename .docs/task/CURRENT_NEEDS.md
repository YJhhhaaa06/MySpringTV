# 当期需求（Current Needs）

> **定位**：登记**当期要做、以及新发现待消化**的需求 / 痛点 / 方向，是「这一期做什么」的**决策唯一源（Why）**。
> **工作流**：登记（N# / R-##）→ 评审拍板（纳入 / 留池 / 废弃）→ 拆任务（进 `CURRENT_TASKS.md` 的 T#）。
> **与任务文件的关系**：本文件只回答**要不要做、为什么**；怎么做在 `CURRENT_TASKS.md`。
> **边界（不在这里登记的）**：执行中遇到的问题 → `CURRENT_ISSUES.md`；本期不解决的 → `FURTHER_ISSUES.md`。
>
> ★ **膨胀控制（2026-10-11 起执行）**：**已拍板并交付的 R-## 在期收尾时清出** —— 结论与理由收编进
> [收藏功能-分期与设计.md](收藏功能-分期与设计.md) **附录「编号索引」**（**理由不再留在这里**），
> 因为代码 / 测试注释里有大量 `R-##` 引用，需要一处**跨期稳定**的归宿。
> 跨期未决项保留编号结转。**编号不回收**（下期 **R-12** 起）。
