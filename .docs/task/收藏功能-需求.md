# 收藏功能 —— 功能需求（用户视角）

> **定位**：本篇只记 **用户看得到的行为与规则**，是"要做成什么样"的事实源。
> **不写**：分几期、任务怎么拆、表怎么建、端点怎么命名 → 全部在 `收藏功能-分期与任务.md`。
>
> 参照系是 B 站。**本仓与老项目都无收藏实现**，故规格以 B 站为准（不似迁移期有行为规格书可依）。

---

## 一、这是什么

用户可以把自己喜欢的内容收进若干个**收藏夹**，分类保存、随时回看。

与点赞的两处不同，用户能直接感知：

1. 点赞是"一下"，收藏是"收进某个夹" —— **收藏是有归属的**；
2. 同一个内容可以**同时出现在我的多个收藏夹里**。

---

## 二、收藏夹（容器）

| 功能 | 用户看到什么 | 本项目 |
|---|---|---|
| 默认收藏夹 | 每个用户自带一个"默认收藏夹"，**删不掉**；收藏时没选夹，内容自动进这里 | 纳入 |
| 新建收藏夹 | 起个名字就能新建 | 纳入 |
| 改名 | 随时改收藏夹的名字 | 纳入 |
| 删除收藏夹 | 删掉整个夹；夹内的收藏一并消失，**视频本身不受影响** | 纳入 |
| 收藏夹列表 | 看到我全部收藏夹，含每个夹里有多少条 | 纳入 |
| 简介 | 给收藏夹写一段说明文字 | 待定 |
| 封面 | 自定义封面；没设就用夹内最新一条的封面 | 待定 |
| 公开 / 私密 | 设成私密后，这个夹**不在我的个人主页出现**，别人看不到 | 纳入 |

---

## 三、收藏与取消

| 功能 | 用户看到什么 | 本项目 |
|---|---|---|
| 收藏 | 内容页点"收藏"，勾选一个或几个夹，**一次可进多个夹** | 纳入 |
| 取消收藏 | 从某个夹里移出；若该内容还在别的夹里，那些夹里的不受影响 | 纳入 |
| 收藏状态 | 打开内容页能看到"已收藏"，并知道**收在了哪些夹** | 纳入 |
| 收藏数 | 内容页显示"多少人收藏了它"；**同一个人收进多个夹只算 1** | 纳入 |
| 一内容进多夹 | 同一个视频可以同时躺在我的多个夹里 | 纳入 |
| 收藏夹内容列表 | 打开某个夹，按**收藏时间倒序**看里面的内容 | 纳入 |

## 六、用户看得到的规则

| 规则 | 口径 |
|---|---|
| 收藏数怎么算 | **按人去重** —— 同一人对同一内容，收进 3 个夹也只显示 1 |
| 什么能收藏 | **视频和图文（帖子）都可以** |
| 收藏会不会被别人看到动态 | **不会** —— 收藏**不产生动态**，不进关注流 |
| 容量上限 | **暂不限制**（B 站是：自建夹 99 个 / 单夹 1000 条 / 默认夹 5 万，实测非公示） |
| 公开 / 私密 | 需求成立，但**不是第一批就给**；在那之前全部收藏夹都是公开的 |
| 内容被删了怎么办 | 未定（B 站是保留条目并显示「已失效」） |

> ⚠️ 容量数字来自社区实测，**B 站未官方公示**。若将来要设限，别直接照抄。

## 七、明确不做（未经证实）

| 说法 | 处置 |
|---|---|
| 收藏夹**二级分组**（把夹再分组） | ❌ 只在 SEO 采集站出现，官方帮助与社区实测均无 → **不作需求**，若要请先去 B 站界面证实 |
| **智能筛选收藏夹**（按规则自动归类） | ❌ 同上，大概率是生成内容杜撰 → **不作需求** |
