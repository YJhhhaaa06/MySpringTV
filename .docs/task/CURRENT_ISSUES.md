>
> ★ **膨胀控制（2026-10-11 起执行）**：处理完即标状态；**期收尾时把正文清出**（归宿 = git commit），本表只留一行摘要。
> 清出前**必须先把编号收进** [收藏功能-编号索引.md](收藏功能-编号索引.md)
