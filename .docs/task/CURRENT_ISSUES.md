| 去向 | **待裁决**（建议在 `T58` 或 `T62` 收口时定）：① 加 413 类别 + `UPLOAD_TOO_LARGE` 码（语义最准，需同步 §2.1 / §2.2 / 前端字典）；② 归入既有 400 + `PARAM_INVALID`（不加类别，代价是"文件太大"与"参数不合法"同状态）；③ 维持 500（不推荐：等于承认"用户输入可触发服务器错误"）。 |
