## 一、这是什么

用户可以把自己喜欢的内容收进若干个**收藏夹**，分类保存、随时回看。

与点赞的两处不同，用户能直接感知：

1. 点赞是"一下"，收藏是"收进某个夹" —— **收藏是有归属的**；
2. 同一个内容可以**同时出现在我的多个收藏夹里**。

> ★ **稍后再看**（§五）是**独立于收藏夹**的第二个池子 —— 它**不是**一个收藏夹，语义与入口都与收藏并列。

## 二、收藏夹（容器）

| 功能 | 用户看到什么 | 本项目 |
|---|---|---|
| 默认收藏夹 | 每个用户自带一个"默认收藏夹"，**删不掉**；收藏时没选夹，内容自动进这里 | 纳入 |
| 新建收藏夹 | 起个名字就能新建 | 纳入 |
| 改名 | 随时改收藏夹的名字 | 纳入 |
| 删除收藏夹 | 删掉整个夹；夹内的收藏一并消失，**视频本身不受影响** | 纳入 |
| 收藏夹列表 | 看到我全部收藏夹，含每个夹里有多少条 | 纳入 |
| 简介 | 给收藏夹写一段说明文字 | 待定（`description` 列已建但实体 / 端点 / UI 全没接） |
| 封面 | 自定义封面；没设就用夹内最新一条的封面 | ❌ **不做**（2026-10-14 拍板；继续留池） |
| 公开 / 私密 | 设成私密后，这个夹**不在我的个人主页出现**，别人看不到 | 纳入 |
| 看别人的收藏夹 | 个人空间页有「收藏夹」模块，列出他的**公开**夹（名称 + 视频数），且**可以点开看夹里的内容**；私密夹**完全不出现** | 纳入 — 口径与骨架见 [favorite](./favorite.md) **§十** |

## 三、收藏与取消

| 功能 | 用户看到什么 | 本项目 |
|---|---|---|
| 收藏 | 内容页点"收藏"，勾选一个或几个夹，**一次可进多个夹** | 纳入 |
| 取消收藏 | 从某个夹里移出；若该内容还在别的夹里，那些夹里的不受影响 | 纳入 |
| 收藏状态 | 打开内容页能看到"已收藏"，并知道**收在了哪些夹** | 纳入 |
| 收藏数 | 内容页显示"多少人收藏了它"；**同一个人收进多个夹只算 1** | 纳入 |
| 一内容进多夹 | 同一个视频可以同时躺在我的多个夹里 | 纳入 |
| 收藏夹内容列表 | 打开某个夹，按**收藏时间倒序**看里面的内容 | 纳入 |

## 五、周边（B 站有，本项目逐项表态）

| 功能 | 用户看到什么 | 本项目 |
|---|---|---|
| 稍后再看 | 一个**独立于收藏夹**的"稍后再看"池：**只能加视频**（图文帖不进）；内容页点「稍后再看」即加入；**已在池中的内容再次加入 ⇒ 移到最前**（看起来像刚加的）；可在池里把内容**挪进普通收藏夹** | ★ **纳入**（2026-10-14 拍板；落地 = **独立表 + 独立端点**，与收藏夹**不共表**）。三条实测语义见 §六；骨架见 [favorite](./favorite.md) **§九** |
| 订阅别人的公开收藏夹 | 别人的公开夹可以被我"收藏"下来 | ❌ **不做**（2026-10-14 拍板：B 站 也只有"订阅**视频合集**"、没有"订阅收藏夹"，而本项目没有视频合集） |
| 失效内容 | 视频被作者删除 / 下架后，夹里仍占一个位置，显示一张**没有封面、标题位写「内容已失效」的灰卡片**；**看不到原标题，也看不到原作者**；不自动清理 | **纳入**（一期就做脱敏占位 VO；卡片**样式**归前端体验优化，见 `task/FURTHER_ISSUES.md` **F-15** 同族） |
| 失效条目的操作 | **可以移出收藏夹**，但**不能移入 / 移动到别的收藏夹**（B 站实测，2026-10-08） | 纳入 |
| 全局隐私开关 | 一个总开关，一键隐藏我**所有**收藏（优先级高于单个夹的公开设置） | 待定（★ 2026-10-14 明确**本期不做**，继续留池） |
| 连播 | 一键顺序播放整个收藏夹 | ❌ **不做**（2026-10-14 拍板） |

## 六、用户看得到的规则

| 规则 | 口径 |
|---|---|
| 收藏数怎么算 | **按人去重** —— 同一人对同一内容，收进 3 个夹也只显示 1 |
| 什么能收藏 | **视频和图文（帖子）都可以** |
| 收藏会不会被别人看到动态 | **不会** —— 收藏**不产生动态**，不进关注流 |
| 容量上限 | ★ **2026-10-14 纳入（数字砍一砍）**：默认夹 **5000** 条 / 自建夹 **500** 条 / 自建夹最多 **20** 个（默认夹不计入）。⚠️ B 站 实测是 5 万 / 1000 / 99 且**官方未公示** ⇒ 本仓**刻意取更小的演示值**（数字只走配置常量，改数不动代码）。★ 它是**软上限**：超限的写入请求 ⇒ 400，但**并发下可能瞬时越过**（越界之后不再接受新增）；**读路径不会因此隐藏或限制任何东西** —— 越界的夹照常列出来、照常打得开 |
| 收藏夹能不能重名 | **可以重名**（**B 站实测确认，2026-10-14**）⇒ **刻意不加** `(user_id, name)` 唯一键，同名夹是合法状态 |
| 公开 / 私密 | **一期就给**（2026-10-08 拍板：列在建表时加是零成本，且"默认公开"一旦上线就成了对外契约） |
| 失效条目里能看到什么 | **只有占位**：无封面、标题位「内容已失效」；**不返回原标题 / 封面 / 作者信息**（B 站口径，2026-10-08）。保留条目标识以便移出 |
| 失效条目占不占位置 | **占** —— 夹内视频数与分页都把它算进去（B 站实测，2026-10-08）；分页按**收藏记录**分页，失效记录占一条、返回一条占位 |
| 失效条目能做什么 | **可移出**，**不可移入 / 移动到别的夹**（B 站实测，2026-10-08） |
| 内容被删了怎么办 | **保留条目并显示「已失效」**（B 站口径，2026-10-08 拍板）。⚠️ 本仓媒体是静态直出，已失效内容的**媒体 URL 仍可直连下载** —— 与 B 站不一致，属内容域议题，见 `task/FURTHER_ISSUES.md` **F-10** |
| 稍后再看能加什么 | **只能加视频**（图文帖不进；非视频内容 add ⇒ **400**）。B 站实测，2026-10-14 |
| 稍后再看重复添加 | **已在池中 ⇒ 再次加入把该条移到最前**（不新增、不报错）；**已满时**，加**新**内容 ⇒ 400，但"已在池中的内容"再次加入**仍成功**（B 站实测，2026-10-14） |
| 稍后再看的状态可见性 | ★ **除"打开稍后再看清单"外，任何地方都看不出某视频是否在稍后再看中** —— 内容页**没有**"已加入"状态、列表页 / 详情页**没有** `isWatchLater` 之类的字段（B 站实测，2026-10-14） |

> ⚠️ B 站 的容量数字来自社区实测、**官方未公示** ⇒ 本仓已按用户 2026-10-14 的口径**砍一砍**取更小值
> （见 §六 上表）—— **别把 B 站 的数字当规格**。
