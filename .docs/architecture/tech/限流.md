# 限流（RateLimit）

> 定位（先读这一句）：限流是"**按记账主体给请求与后台任务记一笔令牌账**"的横切机制 ——
> 两个记账主体（请求 / 任务）、两个桶（**用户桶** per-key / **服务器桶**全局单桶）、一条**非对称扣减**规则。
> **本篇是限流的活事实源**：结论从代码 / 配置取证，随 `T24`–`T29` 逐段长大。
> ⚠️ 本仓**没有真实流量** ⇒ 所有数值都是"拍"的，靠「来源 + 推翻条件」登记，**不靠数值可信**；
> 数值与锚点的正文写在 `application.yaml` 的 `video.rate-limit` 段注释里（改数只动那里 + 配置类）。
> **设计与论证**（为什么这么定、否决了什么）不属本篇：开工期在 [限流设计稿](../../task/限流-设计稿.md)，
> 收口后随 `T29` 按归档 SOP 冻结。

## 一、算法与账本（【待 T24 / T25 落地后填】）

讲什么：两个记账主体各自的扣减语义、"**用户桶无条件扣 / 服务器桶条件扣**"这条非对称规则，
以及它为什么能把"两桶同时扣"的原子性要求**消掉**。
依据 = 设计稿 §一 / §二 / §三；落到代码后本篇只记**已实现的行为**与 `类#方法` 锚点。

## 二、配置与参数（结构已落地，值不在此处）

讲什么：`video.rate-limit` 的键路径与配置字段的对应、绑定期校验的**四条口径**
（为正 / 权重表键形态 / `miss-multiplier ≥ 1` / `reject-discount ∈ [0,1]`）、以及环境变量覆盖面。

★ **一条必须知道的事实**：`cost.base` 的键在 YAML 里**必须**用方括号括起来
（`"[POST /favorite/add]": 3`）—— Spring 绑 `Map` 时会把键里"小写字母数字与 `-` 之外"的字符
**静默删掉**（漏写则 `POST /favorite/add` 变成 `POSTfavoriteadd`，无报错、权重永远命不中）。
实测记录与理由在 `application.yaml` 该段注释 + `RateLimitProperties` 类注释；配置类把键形态钉成
**绑定期校验** ⇒ 漏写方括号是**启动失败**而不是静默放行。

⚠️ 未经环境变量暴露的只有 `cost.base`（键含空格，环境变量名无法表达）：要覆盖它在测试里用
`@TestPropertySource(properties = "video.rate-limit.cost.base.[POST /x]=2")`。

## 三、接线与覆盖范围（【待 T25 落地后填】）

讲什么：过滤器链的**实测顺序**（`RequestIdFilter` → `AccessLogFilter` → Security 链 →
`JwtAuthFilter` → **限流器** → `DispatcherServlet`）、覆盖范围（跳过静态 / `/actuator`，其余全过闸）、
429 出口形态（自写信封 + `Retry-After` + 补记业务码属性）、`CacheUnavailableException` ⇒ 放行（fail-open）。
⚠️ 链序一旦变动，须同步 [安全与鉴权](./安全与鉴权.md) 的链序表。

## 四、成本信号（【待 T26 / T27 落地后填】）

讲什么：三条信号的**实际取得方式** —— ①端点权重表（未登记 ⇒ `default-base`，不是 0）；
②本次请求的缓存 miss 计数（回传机制的落地形态）；③任务成本（在**执行处**无条件扣服务器桶、
不碰用户桶）。依据 = 设计稿 §三 / §四。

## 五、可观测（【待 T28 落地后填】）

讲什么：指标名与标签、日志**三档**（拒绝 WARN 结论行 / Redis 不可达放行 WARN /
**脚本与返回解析异常 ERROR**）、以及"拒绝日志不落原始 key（匿名不落 IP）"的口径。
依据 = 设计稿 §十；出口脱敏一律走 [可观测](./可观测.md) 的既有出口，**不在调用点手写**。

## 六、测试口径与已知代价（【待 T29 收口时填】）

讲什么：默认回归集覆盖的契约、**反向验证**清单（改哪行实现必须变红）、`resilience` 组的故障注入，
以及已知代价（数值是拍的 / 后台忙⇒前台更易被限 / 测试环境匿名桶退化成全局限流 / Redis 进入关键路径 /
fail-open 期等于没限流 / 服务器桶可为负 / 反代 NAT 的 IP 语义未处理）。
⚠️ **测试夹具口径**：MockMvc 里匿名请求的 IP 全是 `127.0.0.1` ⇒ 匿名桶退化成"全局限流"；
所有桶参数都可环境变量覆盖，**非限流测试若被误伤可整体调大**（见 `task/CURRENT_TASKS.md` `T25`）。
